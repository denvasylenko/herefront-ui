## When to use which

| Style | When | Apple |
| --- | --- | --- |
| `filled` | The one main action of the screen. Never two side by side. | Filled (prominent) |
| `tinted` | Important, but not the main one. | Tinted |
| `gray` | Ordinary actions. The default. | Gray |
| `plain` | Tertiary, inside a row, “Cancel”. | Plain |
| `destructive` | Delete, switch off. | Destructive |
| `glass` | Over a photo or a busy background. | Glass |

## Behaviour

- It sinks a little the moment you press and fires when you **release**; slide your finger off and nothing happens.
- Disabled is faded and does nothing — say next to it why it is disabled.
- `Tab` reaches it, `Enter` and `Space` press it; the focus ring shows only for the keyboard.

## API

| | |
| --- | --- |
| Attributes | `variant` (`filled` · `tinted` · `gray` · `plain` · `destructive` · `glass`), `size` (`small` · `medium` · `large`), `disabled`, `block` |
| Slots | default — the label; `icon` — an icon before it |
| Parts | `button` |
| Events | `click` (not fired while disabled) |
