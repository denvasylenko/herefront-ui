Every component below is live: press, slide, switch. Open one to change its variants and copy the markup.
They are web components (`<hf-…>`), so they work in React, in a plain page and on server-rendered sites, and they take
their colours from the [tokens](../tokens/), so any [theme](../themes/) repaints them.

```html
<link rel="stylesheet" href="tokens.css">
<script src="components.js" defer></script>
```
