## When to use

For 2–5 mutually exclusive views of one thing: List / Map, 7 / 30 / 90 days. More than five, or different actions —
use [chips](../chip/) or a menu.

## Behaviour

- The choice is instant and the white thumb **slides** to it with a small spring.
- All segments are the same width; labels never get cut.
- `←` / `→` move the choice when the control has focus.

## API

| | |
| --- | --- |
| Content | `<option value="…">Label</option>` for each segment |
| Attributes | `value`, `size` (`medium` · `large`), `block`, `aria-label` |
| Property | `value` |
| Parts | `track`, `thumb`, `segment` |
| Events | `change` — `event.detail.value` |
