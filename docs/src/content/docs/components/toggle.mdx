## When to use

Only for a setting that takes effect immediately — no “Save” button after it. Not for actions, and not a checkbox:
checkboxes are for picking several items of a list.

## Behaviour

- The whole row toggles, label included, as in Settings.
- While you press, the knob stretches; it slides across with a spring.
- `Space` or `Enter` toggles it from the keyboard. If saving fails, put it back and say why.

## API

| | |
| --- | --- |
| Attributes | `checked`, `disabled`, `aria-label` (if there is no visible label) |
| Slots | default — the label |
| Property | `checked` |
| Parts | `switch` |
| Events | `change` — `event.detail.checked` |
