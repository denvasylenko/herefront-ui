## When to use

Quick filters above a list, suggestions under a chat, active filters you can remove. For 2–5 views of one thing use a
[segmented control](../segmented/) instead.

## API

| | |
| --- | --- |
| Attributes | `selectable` (toggles on press, `aria-pressed`), `selected`, `removable` (shows ✕), `remove-label`, `disabled` |
| Slots | default — the label; `icon` |
| Parts | `chip`, `remove` |
| Events | `change` — `event.detail.selected`; `remove` |
